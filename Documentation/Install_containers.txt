dnf -qy module disable postgresql

🪜 3. Installer PostgreSQL 18

dnf install -y postgresql18-server postgresql18

su - postgres

/usr/pgsql-18/bin/initdb -D /var/lib/pgsql/18/data

🪜 3. Démarrer PostgreSQL
Toujours en tant que postgres :

/usr/pgsql-18/bin/pg_ctl -D /var/lib/pgsql/18/data -l logfile start

🪜 4. Vérifier le statut

/usr/pgsql-18/bin/pg_ctl -D /var/lib/pgsql/18/data status

🪜 5. Tester la connexion

/usr/pgsql-18/bin/psql


🪜 6. (Optionnel) Arrêter proprement

/usr/pgsql-18/bin/pg_ctl -D /var/lib/pgsql/18/data stop

🧩 Étapes pour corriger et démarrer PostgreSQL dans le conteneur
1️. Vérifier et créer le dossier de log

su - postgres
cd /var/lib/pgsql/18/data
mkdir -p log
chmod 700 log

2️. Vérifier que le répertoire de données appartient à postgres
chown -R postgres:postgres /var/lib/pgsql/18/data
chmod 700 /var/lib/pgsql/18/data

3️. Rediriger le log vers un fichier simple
/usr/pgsql-18/bin/pg_ctl -D /var/lib/pgsql/18/data -l /var/lib/pgsql/18/data/postgres.log start

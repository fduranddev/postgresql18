1. Processus principal:

/usr/pgsql-18/bin/postgres -D /data/pg18

* C’est le serveur PostgreSQL lui-même, qui lit les fichiers de données dans /data/pg18.

2. Processus secondaires (workers et background):

* logger → gère les logs
* checkpointer → écrit régulièrement les données sur le disque
* background writer → optimise l’écriture des pages modifiées
* walwriter → écrit les journaux WAL
* autovacuum launcher → gère le nettoyage automatique
* logical replication launcher → pour la réplication logique
* io worker → gestion des entrées/sorties

* C’est juste la commande que tu viens de lancer pour chercher postgres.

1. Création du fichier `dockerfile`

# Dockerfile pour PostgreSQL 18 sur Rocky Linux
FROM docker.io/rockylinux/rockylinux:latest

# Mainteneur
LABEL maintainer="fdurand2015@gmail.com"

# Installer les utilitaires de base et PostgreSQL 18
RUN dnf -y update && \
    dnf -y install wget dnf-utils epel-release sudo && \
    dnf -y install https://download.postgresql.org/pub/repos/yum/reporpms/EL-8-x86_64/pgdg-redhat-repo-latest.noarch.rpm && \
    dnf -qy module disable postgresql && \
    dnf -y install postgresql18 postgresql18-server postgresql18-contrib && \
    dnf clean all

# Créer l'utilisateur postgres et le répertoire de données
RUN mkdir -p /var/lib/pgsql/18/data && \
    chown -R postgres:postgres /var/lib/pgsql && \
    chmod 700 /var/lib/pgsql/18/data

# Copie du script d'initialisation
COPY entrypoint.sh /entrypoint.sh
RUN chmod +x /entrypoint.sh

# Exposer le port PostgreSQL
EXPOSE 5432

# Définir l'utilisateur par défaut
USER postgres

# Commande de démarrage
ENTRYPOINT ["/entrypoint.sh"]

==============================================================================================
entrypoint.sh

#!/bin/bash
DATA_DIR="/var/lib/pgsql/18/data"

# Initialiser la base si nécessaire
if [ ! -f "$DATA_DIR/PG_VERSION" ]; then
    /usr/pgsql-18/bin/initdb -D "$DATA_DIR"
fi

# Configurer PostgreSQL pour écouter toutes les interfaces
sed -i "s/#listen_addresses = 'localhost'/listen_addresses = '*'/g" $DATA_DIR/postgresql.conf
sed -i "s/#port = 5432/port = 5432/g" $DATA_DIR/postgresql.conf

# Autoriser toutes les connexions TCP
echo "host all all 0.0.0.0/0 trust" >> $DATA_DIR/pg_hba.conf

# Démarrer PostgreSQL au premier plan (PID 1)
exec /usr/pgsql-18/bin/postgres -D "$DATA_DIR"
